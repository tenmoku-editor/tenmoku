## New

- **Preview releases.** This is the first one. To get them, choose preview in Settings > Update > Channel, or set `channel = "preview"` under `[update]`. This works where Tenmoku updates itself.
- **Mermaid diagrams.** The Markdown preview draws a `mermaid` code block holding a flowchart or sequence diagram as a diagram, and shows one it can't draw as code with a note saying why.
- Syntax highlighting you can install for Angular templates, Assembly (x86, ARM, GAS and NASM), Batch files, BibTeX, Bicep, Common Lisp, CUDA C++, Cython, Devicetree, Emacs Lisp, GDScript, Graphviz DOT, HTTP request files, Lean 4, Luau, MATLAB, Mermaid, Meson, Nushell, reStructuredText and Wolfram Language.
- **Blocks.** A falling-blocks game, as an optional plugin that is never installed by default. Tenmoku can't download plugins from the registry yet, so download its archive from the `tenmoku-editor/registry` releases on GitHub, install it with Extensions: Install from File or Folder…, set `plugins_preview = true` under `[extensions]`, and run Blocks: Play.
- A plugin can show its own panel and give it focus with `panels.reveal`.

## Improved

- Progress spinners, including the one in the status bar, turn smoothly.
- With both the Objective-C and MATLAB grammars installed, a `.m` file is highlighted as one or the other according to its content, and as Objective-C when that isn't clear.
- Home and End move to the first and last item in the project tree's right-click and New menus and in the Graph's right-click menu.

## Fixed

- Semantic highlighting no longer gives up while rust-analyzer is slow to start, which left restored tabs without mutable-variable underlines and format string colours.
- In the Yohen, Hakuji and Tenmoku Ember themes, tags no longer share the keyword colour, so template syntax stands apart from the HTML around it.
- On macOS and Linux, a `gradlew` or `mvnw` that isn't executable is no longer used for project tasks; the installed `gradle` or `mvn` runs instead.
